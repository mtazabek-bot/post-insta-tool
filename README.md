# post-insta tool — карточки для Instagram из текста

Открыть в браузере: **https://mtazabek-bot.github.io/post-insta-tool/**

Открыть `index.html` двойным щелчком. Интернет не нужен: шрифты, иконки и экспорт — внутри файла.
Файл можно скинуть коллеге в мессенджер или на флешку, он заработает на любом компьютере.

## Проект: Tazabek или Turmush

На входе инструмент спрашивает проект. Проект задаёт логотип, палитру карточек и оформление
обложки; сменить его можно в любой момент кнопкой **проект** в шапке.

- **Tazabek** — фирменный красный `#9a2d25`, темы «светлая», «тёмная», «бумага».
- **Turmush** — акцент `#7952B3` и мягкий `#f1ddff`, темы «светлая», «сирень», «тёмная».
  Издание кыргызскоязычное, поэтому у него по умолчанию кыргызские технические надписи:
  «Булагы:» вместо «Источник:», «сүрүңүз →» вместо «листайте →», финальный слайд ведёт
  на turmush.kg. Обложка получает заставку поверх фотографии: плашка с аккаунтом в углу,
  полоса с заголовком капителью, строка сайта внизу.

В шапке каждой карточки стоит настоящий логотип проекта: на светлых темах — акцентом,
на тёмных и поверх фотографии — белым.

Все технические надписи собраны в разделе **технические надписи** и правятся руками.
Кыргызские формулировки в нём предложены, а не утверждены: проверьте по редакционной норме,
правки сохраняются в браузере.

Аккаунт, финальный слайд и хештег издания подставляются под выбранный проект. Свои правки
в этих полях сохраняются: значения по умолчанию берутся только при переходе на другой проект.

## Как пользоваться

0. При первом запуске в работе **одна карточка-обложка** с подсказкой вместо текста —
   чужой пример стирать не надо.
1. Вставить текст новости в поле слева → **собрать карточки из текста**.
   Первая строка станет заголовком, предложения с цифрами — карточками с крупной цифрой,
   остальное разложится по слайдам и списку фактов.
2. Заполнить **источник** — он виден на каждом слайде. Метка, рубрика, аккаунт и дата — там же.
3. Поправить слайды можно двумя способами, они связаны в обе стороны:
   - **прямо на карточке** — двойной щелчок по тексту открывает поле поверх него,
     `Ctrl+Enter` фиксирует, `Esc` отменяет; блок слева обновляется на каждом символе;
   - **в блоке слева** — сменить тип, переставить ↑↓, удалить ✕, добавить «+ слайд»;
     пункты списка по одному в строке.
4. **Двигать и масштабировать.** Щелчок по тексту берёт его: перетаскивание двигает блок,
   колесо меняет кегль, ручка справа — ширину. Щелчок по фону берёт фотографию: её так же
   можно двигать и уменьшать колесом (масштаб опускается ниже 100%, тогда по краям
   показывается фон темы). Кнопки под карточкой делают то же самое, `⟲` возвращает
   объект на место.
5. Размер превью — переключатель **S / M / L** в шапке: L показывает карточку почти
   в натуральную величину, 880 px против 1080 px реального файла.
4. Формат и тему выбрать сверху: **4:5** для ленты (максимум площади), **3:4** если важно,
   чтобы превью не резалось в сетке профиля, **9:16** для сторис.
5. Фото — перетащить в окно или «+ фото», затем в редакторе слайда выбрать его из списка.
   Кроп: тащить мышью прямо по карточке, зум — колесом.
6. **safe-zone** показывает, что срежет сетка профиля и что закроет интерфейс.
   **лента профиля** показывает, как карточки лягут в сетку 3:4.
7. **PNG** под карточкой — скачать одну. **скачать всё (PNG)** — каждая карточка
   отдельным файлом 1080 px, без архива: браузер один раз спросит разрешение на
   несколько загрузок, дальше складывает файлы в папку загрузок по порядку.
   Кнопка **zip** рядом — то же самое одним архивом плюс файл `подпись.txt`
   с готовой подписью и хештегами.

## Safe zone: одного числа «по кругу» не бывает

В ленте интерфейс Instagram **на картинку не наезжает** — там работает только кроп сетки
профиля. Наезжает он в сторис и Reels. Отсюда разные минимумы по форматам:

| формат | что срежет сетка профиля 3:4 | что закроет интерфейс |
|---|---|---|
| 4:5 (1080×1350) | по **34 px** с каждой стороны | ничего |
| 3:4 (1080×1440) | не срезает | ничего |
| 1:1 (1080×1080) | по **135 px** с каждой стороны | ничего |
| 9:16 (1080×1920) | **240 px** сверху и снизу | сверху 190, снизу 400, справа 120, слева 60 |

Ползунок **поле карточки** задаёт свой отступ (по умолчанию 88 px), но инструмент не даст
уйти ниже того, что срежет сетка или закроет интерфейс: в 9:16 подвал автоматически
опускается до 400 px. Подпись под ползунком каждый раз показывает итоговые четыре числа.

Кнопка **safe-zone** рисует всё это поверх карточки: красным — кроп сетки профиля,
оранжевым — интерфейс сторис, синим — центральные 80% кадра, зелёным — рабочее поле
текста. Числа подписаны прямо на полосах.

Источники и замеры — `references/research_smm_2026.md` §2 внутри скилла `post-insta`.

## Что важно знать

- Экспорт всегда 1080 px по ширине — ровно то, что просит Instagram; больше грузить бессмысленно,
  площадка всё равно уменьшит и картинка станет мягче.
- Safe-zone в файл не попадает — это только экранная подсказка.
- Оптимум по исследованиям — 8 слайдов: первый продаёт свайп, последний просит сохранить
  и отправить. Пустые слайды «для объёма» вредят.
- Кегль ниже 34 px на 1080 не читается с телефона, поэтому инструмент сам уменьшает шрифт
  только до этой границы, а дальше просит сократить текст.
- Проект, формат, тема и черновик сохраняются в браузере (localStorage). Фотографии не сохраняются — их надо
  добавить заново после перезапуска.
- Подпись: первые 125 знаков видно до «ещё», хештегов 6–8 тематических.

## Если надо поправить сам инструмент

Правится `index.src.html`, потом собирается:

```bash
python build_tool.py --dir .        # скрипт лежит в скилле post-insta
```

Сборка вшивает шрифты в `index.html`. Прямо в `index.html` править не надо — перезапишется.

Инструмент — часть скилла `post-insta`: из текста новости он делает карточки-карусели,
а скилл умеет ещё и вертикальные ролики. Исследования и обоснования решений по форматам,
кеглю и структуре колоды — в `references/research_smm_2026.md` скилла.

Лицензии вшитых шрифтов — [THIRD-PARTY.md](THIRD-PARTY.md).
